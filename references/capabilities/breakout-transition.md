## R

> If premise changes, change trading style. (Video 52B, PDF p1354; also p1364, p1374)

前提改变时必须改变交易风格。作者在三个场合重申此横切元规则。突破阶段结束的信号包括：对方剥头皮者开始赚钱（p292-293）、回撤跌破突破点（p434/p520）、跟随不足（p200/p802）。

## I

突破阶段不会永远持续。识别突破何时结束、该切换到哪套规则，是避免"在通道里继续用突破方法"的关键。核心信号不是单一指标，而是多个线索的累积：当对方的剥头皮者开始稳定获利（说明反向力量已足够强）、当价格回撤跌破突破起点（说明突破动能耗尽）、当连续 K 线缺乏跟随（bad follow-through）时，突破阶段的假设就不再成立。此时必须切换——从只顺势变为双向或逆势，从 BTC/STC 变为限价单 BLSHS。元规则"前提改变就改变风格"是所有状态切换的上位原则。

## A1

**合成演练**（原书未提供专门的切换案例；以下基于 p292-293/p434 的规则描述构造）

场景：Emini 5 分钟图，开盘后出现 8 根连续牛市 K 线的强突破。第 9–11 根 K 线开始出现小实体和上影线，第 12 根 K 线收盘低于第 8 根低点。同时观察到空头限价卖单开始在 1–2 点利润处成交（对方剥头皮者开始赚钱）。

判定：突破阶段结束的至少两个信号同时出现（跟随不足 + 对方剥头皮者获利）。应切换为通道或 TR 规则集。

回顾要点：此演练可按原书规则复算，但具体 K 线数和价位为构造值，非作者原例。实际应用中需结合完整图表上下文。

## A2

触发场景：
1. 用户问「突破结束了吗 / Is the breakout phase over」→ 执行切换信号核对
2. 用户问「什么时候换方法 / When to switch methods」→ 前提改变就改风格
3. 用户说「追进去就不动了 / No follow-through after entry」→ 跟随不足信号
4. 用户问「现在该用什么规则集」→ 根据新状态指引到对应卡
5. 用户说「对方开始赚钱了 / Opposite side making money」→ 关键切换信号

区分：
- 本卡不处理突破期入场（BTC/STC），见 `strong-bo-entry`
- 本卡不处理目标状态的详细操作规则，见各状态卡（`tight-channel` / `broad-channel` / `trading-range`）
- 本卡不处理被套处置，见 `trapped-disposal`

关键词：突破结束 / breakout end / 方法切换 / premise change / 跟随不足 / bad follow-through / 风格切换 / style switch

## E

### 输入契约

必需字段：
- K 线图或行情描述（含突破起始至今的完整走势）
- 当前持仓方向与入场价（若有持仓）
- 此前判定的市场状态（若未提供，先调用 `market-cycle-diagnosis`）

缺失任一时询问用户，不得猜值。

### 步骤

1. **核对切换信号**（多源累积，无单一门槛）：
   - □ 对方剥头皮者开始赚钱（p292-293）：反向限价单稳定成交并获利 1–2 点以上
   - □ 回撤跌破突破点（p434/p520）：价格回到突破起始 K 线的起点以下/以上
   - □ 跟随不足（p200/p802）：连续 K 线缺乏同向动量，出现小实体、长影线、重叠增多
   - □ 出现 2–5 根强反向 K 线（p1354）：Always In 方向可能翻转

   完成标准：≥2 个信号同时出现 → 高置信度切换；1 个信号 → 提高警惕但不一定切换；0 个信号 → 维持当前规则集。

2. **应用元规则**（p1354/p1364/p1374）：
   - "If premise changes, change trading style"
   - 前提 = 此前对市场状态的判定；当证据表明状态已变，立即切换管理方式

3. **确定新规则集**：
   - 突破 → 紧通道：转 `tight-channel`（只顺势，但不再 BTC）
   - 突破 → 宽通道：转 `broad-channel`（双向，预期深回撤）
   - 突破 → TR：转 `trading-range`（BLSHS，限价单，80% 规则）
   - Always In 方向翻转：平掉旧方向仓位，按新方向操作

4. **持仓处置**：
   - 已有顺势持仓且切换信号出现 → 考虑保本退出或收紧止损
   - 失望时出场以避免亏损而非为了获利（p1348-1350）
   - 无法解释市场为何反向 → 先退出观望（c22）

5. **判停点**：
   - 仅 1 个弱信号且持仓盈利 → 可提高警觉但不强制切换
   - 用户拒绝承认前提已变 → 引用 c21 警告
   - 信息不足以判定 → 暂停结论，要求补充数据

### 输出契约

| 字段 | 类型 | 说明 |
|------|------|------|
| switch_signals | checklist | 各信号的核对结果 |
| confidence | enum | high (≥2 signals) / medium (1 signal) / low (0 signals) |
| new_state | string | 切换后的目标状态 |
| new_ruleset_ref | string | 指向对应能力卡的 slug |
| position_action | string | 现有持仓的建议处置 |

## B

**反场景**：
- 仅出现 1 根反向 K 线但整体结构未变 → 可能是正常回调，不必切换
- 突破暂停但未出现任何切换信号 → 可能只是盘整蓄力，维持原规则

**作者警告的失败模式**：
- c21：前提变化时必须改变交易风格（p1357）
- c32：所有趋势最终都会让交易者失望（p1344-1345）
- 不及时切换会导致在通道/TR 中继续用突破规则，来回止损

**批判盲点**：
- 切换信号的判定依赖定性观察，无量化阈值
- "对方剥头皮者开始赚钱"在实际交易中难以实时观测，更多是事后推断
- 前提改变的判定本身依赖状态诊断（task-01/02），形成循环依赖
- 材料未给切换的"确认等待期"——是立即切换还是等 N 根 K 线确认
