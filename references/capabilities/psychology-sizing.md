## R

> Become Objective: Trade the I Don't Care Size. If beginner is scared whenever stop is far, he will make bad management decisions. Good solution is to trade tiny size so that he really does not care if he loses. (Video 51D, PDF p1318-1319)
> Confused Goals: Plan to Swing, but Trade Like Scalp. Beginners often takes trade as swing, but manages as scalp. Not enough risk when 50–60% probability of swing profit. (Video 51A, PDF p1266-1267)

交易小到真的不在乎亏损的大小，才能恢复客观判断。目标混淆——计划摆动却按剥头皮管理——是初学者最常见的心理偏差之一。

## I

作者认为多数亏损来自糟糕的管理而非糟糕的入场（p1278-1280），而坏管理的根源是一系列可识别的心理偏差。本卡将这些偏差整理为自查清单，并给出一个可执行的校准动作——I Don't Care Size：当恐惧、贪婪或任何情绪干扰了客观判断时，把仓位缩小到真的不在乎亏损的程度，先学会做对再逐步增大。偏差清单涵盖：目标混淆（想摆动却按剥头皮管理 c06/c07，或反过来）、拒绝认错（不愿止损反而加仓 c09）、只看风险不看概率与回报（c10/c11）、只看两根 K 线不看全局（c13）、忽略反面论据（c15）、买高卖低的确认偏误（c24）、不做该做的事（c25）、FOMO 与被甩出趋势（c18/p170-174）、在趋势末端等待最强 K 线才入场（c44）。agent 无法检测用户的真实情绪状态，所有偏差诊断以用户自述为依据。

## A1

**worked_example · retrospective: true**

来源：case26（Video 51B, PDF p1290）+ case27（Video 51A, PDF p1266）。

case26 展示初学者拿到好的入场但因恐惧止损距离而过早退出、寻找借口离场、不设市场止损——核心问题是恐惧覆盖了理性分析。case27 展示初学者计划做摆动交易但入场后失去客观性，按剥头皮方式管理被正常回调扫出。两个案例共同例证「大多数亏损来自坏管理而非坏入场」。

回顾要点：case26 对应 c23（好交易坏管理），case27 对应 c06（目标混淆）。两者都是事后复盘图，不得据此推导初学者的亏损率。I Don't Care Size 是作者给出的实操解法（p1318-1319/c38）。

## E

### 输入契约

必需字段：
- 用户自述的交易困扰或行为模式描述
- 最近若干笔交易的简要记录（方向、结果、管理方式）
- 当前使用的仓位大小与止损距离

缺失任一时询问用户，不得猜值。
⚠️ agent 无法检测用户真实情绪，所有诊断以用户自述为依据。

### 步骤

1. **偏差自查清单**（逐一核对）：
   - ① 目标混淆（c06/c07/p1266-1269）：入场时确定的风格（摆动/剥头皮）是否在持仓中被情绪改变？
   - ② 拒绝认错（c09/p1300）：亏损时是否拒绝退出、反而加仓或放宽止损？
   - ③ 只看风险不看概率与回报（c10/c11/p1192/p1306-1307）：是否只因风险小就入场，未验证 Trader's Equation？
   - ④ 只看两根 K 线（c13/p1323）：是否仅凭最近几根 K 线的动量做决策？
   - ⑤ 忽略反面论据（c15/p1326）：是否只看到支持自己方向的证据？
   - ⑥ 买高卖低确认偏误（c24/p1288）：是否在趋势末端对大 K 线追入？
   - ⑦ 不做该做的事（c25/p1289）：明知概率低仍入场且不止损？
   - ⑧ FOMO 与被甩出（c18/p170-174/p179-181）：是否因害怕宽止损而错过整个趋势？
   - ⑨ 趋势末端等最强 K 线（c44/p1287）：观察 10-20 根 K 线后才在最强势时入场？
   - 完成标准：逐条回答是/否/不确定；命中 ≥1 条即进入步骤 2

2. **I Don't Care Size 校准**（p1318-1320/c38）：
   - 当恐惧或任何情绪干扰了客观判断时：
     - 将仓位缩小到**真的不在乎亏损**的程度
     - 目标不是赚钱，而是学会正确决策
     - 在小仓位下反复练习直到能客观执行全部管理规则
     - 然后逐步增大仓位
   - 完成标准：用户确认一个具体的、小到不影响判断的仓位大小
   - ⚠️ 这是学习方法论，不是永久仓位建议

3. **针对性纠正动作**：
   - 目标混淆 → 入场前写下交易风格（摆动/剥头皮），全程按该风格管理
   - 拒绝认错 → 「活着的懦夫好过死去的英雄」（p1300）；目标是赚钱不是坚持原则
   - 只看风险 → 每笔交易必须同时评估风险、回报、概率三者（c10）
   - FOMO → 确认 Always In 方向后立即入场，用 BTC/STC 参与趋势（c18）
   - 完成标准：针对命中的每条偏差给出具体纠正动作

4. **判停点**：
   - 用户描述的亏损模式涉及加仓 → 转 `scale-in` 检查能力门槛
   - 用户没有市场中的止损单 → 引用 c08 转 `protection-exit`
   - 用户连续多次亏损且质疑规则有效性 → 提示复核前提（全局约束第 6 条），不继续机械套用
   - 用户情绪极度激动或表达非理性信念 → 建议暂停交易，agent 不提供心理治疗

### 输出契约

| 字段 | 类型 | 说明 |
|------|------|------|
| biases_detected | list | 命中的偏差编号与描述 |
| idc_size_recommended | boolean | 是否建议 I Don't Care Size |
| idc_size_value | string | 建议的校准仓位大小 |
| corrective_actions | list | 针对性纠正动作 |

## B

**反场景**：
- 当用户的亏损来自技术性问题（如状态判错、止损位计算错误）而非心理偏差时，不应归因于心理——先检查技术层面
- 当用户已经能客观执行管理规则且仓位合理时，不需要 I Don't Care Size 校准

**作者警告的失败模式**：
- c06/c07：目标混淆是初学者亏损的首要心理根源（p1266-1269）
- c09：拒绝认错导致加仓或不止损（p1300）
- c10/c11：只看风险不看概率与回报（p1284/p1306-1307）
- c13：只看两根 K 线不看全局（p1323）
- c15：忽略反面论据（p1326）
- c24：买高卖低的确认偏误（p1288）
- c25：不做该做的事（p1289）
- c18：FOMO 与被甩出趋势（p170-174）
- c44：趋势末端等最强 K 线才入场（p1287）
- c38：I Don't Care Size 是克服恐惧的实操解法（p1318-1320）
- f18 已降 reference 的理由：心理偏差属认知层内容，可执行性弱于其他任务；agent 无法检测用户真实情绪，所有诊断以用户自述为依据，存在信息不对称

**批判盲点**：
- 所有偏差均为定性描述，无客观测量工具；agent 的诊断完全依赖用户自述
- I Don't Care Size 的"小到不在乎"因人而异，材料未给量化标准
- 作者将亏损归因于"坏管理"和"错误信念"，但未排除规则本身在某些市场条件下失效的可能性
- 心理偏差清单来自付费课程讲义，讲者同时是课程销售者——「学不会是你的问题」的叙事框架可能过度归因于学习者
