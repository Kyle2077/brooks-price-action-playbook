## I

磁体位是事前可计算的关键价位，价格倾向于去测试它们。三类磁体：①昨日高/低/收盘价（p1045）——最基础的日内参考位；②更高时间框架（周/月）的支撑阻力位（p1046-1049）——任何更高周期都可能提供重要上下文；③未回补缺口（p969-972）——价格倾向测试缺口另一侧。价格在接近磁体位时可能测试、反转或突破。测试后有三种结果（p1006）：反转、突破后延续、或在磁体位附近形成 TR。磁体位是材料中最可机械化的部分，可用于设定目标、止损和入场触发。「近期天数」的范围材料未定义，agent 应声明此缺口。

## A2

触发场景：
1. 用户问「关键价位在哪 / Where are the key levels」→ 执行磁体位识别
2. 用户问「昨日高低点有什么用 / What about yesterday's high/low」→ 解释磁体效应

5. 用户问「目标看哪 / Where to target」→ 用磁体位作为目标参考

## E

### 输入契约

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| 昨日 H/L/C | 价格 × 3 | 是 | 基础磁体位 |
| 更高时间框架 S/R | 价格列表 | 否 | 周/月级别支撑阻力 |
| 未回补缺口位置 | 价格区间列表 | 否 | 缺口上下沿 |
| 当前价格 | 价格 | 是 | 用于排序磁体位距离 |

### 步骤

1. **标记昨日 H/L/C**（p1045）：
   - 昨日高点、昨日低点、昨日收盘价。
   - 完成标准：三个价位已标记。若缺失 → 先询问。

2. **标记更高时间框架 S/R**（p1046-1049）：
   - 周线、月线图上的明显支撑/阻力位。
   - 「近期天数」范围材料未定义；agent 应声明此缺口并使用用户提供的范围或默认近 4-8 周。
   - 完成标准：至少标记 2-4 个高周期 S/R 位。若无高周期数据 → 仅使用昨日 H/L/C 与缺口。

3. **标记未回补缺口**（p969-972）：
   - 识别近期未回补的价格缺口。
   - 缺口作为磁体：价格倾向测试缺口另一侧。
   - 完成标准：标记所有可见未回补缺口的上下沿。

4. **按距离排序磁体位**：
   - 从当前价格出发，按远近排序所有磁体位。
   - 区分上方磁体（阻力/目标）与下方磁体（支撑/止损参考）。
   - 完成标准：输出有序磁体位清单。

5. **标注测试后三种结果**（p1006）：
   - 对每个磁体位，预期三种可能：①反转（价格触及后折返）；②突破后延续（价格穿越并继续）；③在磁体位附近形成 TR。
   - 完成标准：每个磁体位附带三种结果标签。

### 判停条件

- 缺失昨日 H/L/C → 先询问，不得猜值。
- 多个磁体位密集重叠（如昨日 H 与缺口上沿相差 < 最小剥头皮尺度）→ 合并为一个磁体区域。
- 「近期天数」范围未由用户提供 → 声明材料未定义此范围，使用默认近 4-8 周并注明。

### 输出契约

| 字段 | 说明 |
|------|------|
| 磁体位清单 | 按距离排序的价格列表 + 类型（昨日H/L/C / 周S/R / 月S/R / 缺口） |
| 方向 | 上方磁体 / 下方磁体 |
| 测试后预期 | 反转 / 突破延续 / 形成TR |
| 使用方式 | 目标 / 反转区 / 止损参考 / 突破确认 |
| 缺口声明 | 「近期天数」范围材料未定义 |

## B

**反场景**：
- 只看昨日 H/L/C 忽略更高时间框架 → 遗漏重要的周/月级磁体位。
- 把磁体位当作精确价格而非区域 → 价格可能在磁体位附近波动而非精确触及。
- 多个磁体位冲突时不做优先级判断 → 材料未给优先级规则，agent 应列出全部并说明不确定性。
- 在磁体位处无条件反向入场 → 测试后也可能突破延续，需等待确认信号。

**作者警告的失败模式**：
- c15：忽略反面论据；只看到支持自己方向的磁体位而忽略对立面的磁体位。
- c39：TR 晚期的强突破常是陷阱；磁体位处的突破也可能是假突破。
- c36：好信号在坏上下文中仍然失败；磁体位处的信号也需要上下文支持。

**批判盲点**：
- 「近期天数」（recent days）的范围材料未定义；周/月 S/R 的回溯窗口无标准。
- 多个磁体位冲突时的优先级规则材料未提供。
- 磁体位的「测试」定义无数值门槛（触及、穿越、接近到什么程度算测试）。
- 缺口磁体的有效性随时间衰减，但衰减速度材料未说明。
- 所有磁体位均为事后观察的统计倾向，不构成确定性预测。
