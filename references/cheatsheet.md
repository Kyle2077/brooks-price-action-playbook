# 决策规则速查 — How to Trade Price Action（Brooks Trading Course, Video 37-49 & 51-52）

| 能力 | 一句话规则 |
|---|---|
| 市场周期状态诊断（突破→通道→TR→再突破） | 先判定市场处于突破/通道/交易区间哪一段，再选对应规则集 |
| Always In 方向判定（多/空/中性与翻转触发） | 若此刻被迫必须持单向仓位会选哪个方向——那就是 Always In 方向 |
| 交易者方程与 40-60 规则（这笔值不值得做） | 概率 × 回报 必须大于 风险；低概率要 ≥2x 实际风险，高概率 1x 即可 |
| 止损设置与追踪（Initial/Actual Risk、Base Stop、移动规则） | 同一笔交易止损位与入场点无关；止损远就减小仓位；禁止心理止损 |
| 利润目标与分批获利（2x 减半 / 3x 再减 25% / 摆动剩余） | 默认 2x 初始风险减半、3x 再减 25%、剩余摆动；最小获利 ≥2x 实际风险且 ≥最小剥头皮尺度 |
| 紧通道识别与操作（只顺势，6 特征清单） | 满足 6 特征越多越只顺势；逆势必亏；第一次反向运动通常是次级的 |
| 宽通道识别与操作（90% 的 K 线等同倾斜 TR） | 宽通道 = 倾斜的 TR：90% 的 K 线双向，回撤深（50% 甚至更多） |
| TR / TTR / BOM 识别与操作（80% 规则、买卖区、限价单市场） | TR 中 80% 的突破失败：买低下卖高剥头皮；TTR 不交易；BOM 等方向 |
| 突破阶段结束识别与方法切换（含前提改变则改风格） | 对方剥头皮者开始赚钱 = 突破阶段结束；前提改变就改变交易风格 |
| 强突破入场（Buy/Sell The Close，只顺势） | 强突破中市场大部分时间停在极值附近：买/卖收盘，不等回调 |
| MTR 主要趋势反转验证（三要素 + 腿部量化条件） | MTR 需要强对手方 + 突破趋势线 + 最小利润目标；强腿 ≥5 根或弱腿/TR ≥10 根 |
| 高潮识别与反向操作（Buy/Sell Climax、Micro Channel、TBTL 60/70 分档） | 趋势末段的加速是高潮：一般 60%、极端（微通道/连续高潮）70% 概率出现 TBTL 反向 |
| 第二条腿陷阱识别与反向（专家赌被套者） | TR/倾斜通道中强劲的第二条腿常是陷阱：专家反向，赌被套者被迫平仓 |
| Measured Move 目标计算（腿等距 / 缺口测量，双语义基准） | 腿 1 = 腿 2：用前腿幅度（整根或实体，须声明）等距投影目标 |
| K 线计数入场信号（High/Low 1-4） | 用 High 1/2/3、Low 1/2/3 计数定位回调后的入场信号；High 4 口径仅见案例不作判据 |
| 日内三段结构与时段规则（开盘/中段/尾段 + 当日高低点概率） | 一天分开盘/中段/尾段：90% 的交易日前 90 分钟出现摆动机会；尾段趋势启动窗 12:00-12:35 PST |
| 开盘剧本（BOM / 前 18 根 K 线 / 开盘反转 / 50% 反转口径） | 开盘突破 50% 会反转；第 16-20 根 K 线关注突破或反转；BOM 牛突破 90% 概率牛市或 TR |
| 磁体位识别（昨日 H/L/C + 更高时间框架支撑阻力 + 缺口） | 昨日高低收、高周期支撑阻力与缺口是磁体：价格倾向去测试它们 |
| 时间框架组合（高周期找形态、低周期降风险） | 高时间框架找形态与方向，低时间框架找入场降风险；5 分钟宽通道 = 60 分钟紧通道 |
| 加仓（Scale In）决策：概率换风险，先算最坏情形 | 加仓提高概率但增加风险：先算最坏情形总亏损，止损远就减小仓位；初学者禁止 |
| 三重保护与出场触发（禁心理止损 / 相反信号 / 止损 / 收盘） | 每笔交易三种保护：场内止损 + 相反合理信号退出 + 强反向动量退出；禁止心理止损 |
| 被套/失望处置决策（提前出场 / 保本退出 / 看不懂先退） | 失望就出场以避免亏损而非为了获利；无法解释市场为何反向时先退出观望 |
| 心理偏差自查与仓位控制（目标混淆 / 拒绝认错 / I Don't Care Size） | 多数亏损来自坏管理而非坏入场；怕止损就交易小到不在乎的仓位，先学会做对 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
